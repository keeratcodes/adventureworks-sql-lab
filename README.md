# AdventureWorks SQL Lab

Hands-on SQL project using Microsoft's AdventureWorks2012 database — 
one of the most widely used enterprise datasets in the industry.

## Queries Covered

| File | Description |
|------|-------------|
| 01_person_details.sql | Person info with email, phone and phone type using multi-table JOINs |
| 02_sales_header_may2011.sql | Sales header orders filtered to May 2011 |
| 03_sales_detail_may2011.sql | Line-item sales details for May 2011 |
| 04_total_sales_may2011.sql | Total revenue aggregation for May 2011 |
| 05_monthly_sales_2011.sql | Month-on-month sales trend for 2011 in ascending order |
| 06_customer_total_gustavo.sql | Total lifetime sales for customer Gustavo Achong |

## Concepts Used
- Multi-table JOINs
- Date functions — YEAR(), MONTH(), DATENAME()
- Aggregations — SUM(), GROUP BY
- Filtering and sorting

## Tools
SQL Server · Azure SQL Edge · Docker · VS Code
